## About me

I'm Kevin, a Computer Science student at **UTEP** interested in the connections between **computing, psychology, neuroscience, and biology**.

I'm curious about how people think and behave, how we measure personality and effort, and how computational tools can help us study those questions. I'm also interested in **machine learning and AI for scientific and healthcare applications**.

My projects include Python pipelines for biological data and prediction, browser-based psychology experiments, and Java applications. I use web development, data analysis, and automation to build tools around the questions I'm exploring.

## What I'm into

- **Psychology & neuroscience:** understanding the mind and human behavior.
- **Behavioral research:** personality assessment, test-taker effort, and experimental data collection.
- **Machine learning & AI:** predictive modeling and applications in science and healthcare.
- **Bioinformatics:** biological data, sequence analysis, and research automation.
